# Безопасность

Не включайте токены, cookies и приватные ответы API в issues. Если токен раскрыт, отзовите его в GitVerse.

Локальный auth.json содержит PAT в открытом виде с правами 0600. Не загружайте его в репозиторий или артефакты CI.

Уязвимости сообщайте через приватное сообщение на вкладке Security GitHub-репозитория, если функция доступна. Если нет — откройте issue с просьбой о приватном канале без секретов и деталей эксплуатации.
