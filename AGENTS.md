# GitVerse CLI

Основной пользовательский сценарий — создание PR и ревью. Сначала прочитайте README.md и docs/AGENT-USAGE.md.

* Runtime без внешних зависимостей; Python >=3.10.
* Команды и stdout — JSON, ошибки — JSON в stderr. Не добавляйте интерактивные вопросы в команды для агентов.
* Публичные контракты — gitverse_cli/data/openapi.json. Не предполагайте совместимость с GitHub/Gitea без проверки схемы.
* Внутренний API и публичный API используют разные DTO и авторизацию. Не пересылайте PAT/cookies между ними; не следуйте redirects с credentials.
* Не повторяйте изменяющие запросы автоматически. Не скрывайте неполный diff или достигнутую границу пагинации.
* Не коммитьте токены, cookies, исходные HAR, приватные тела ответов и env-файлы.
* Проверка: python3 -m unittest discover -s tests -v.
* Не публикуйте тестовые PR, комментарии и ревью в пользовательские репозитории без соответствующего поручения. Контрактные тесты не обозначайте как live end-to-end проверку.
